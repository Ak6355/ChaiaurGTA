# CHAI AUR GTA — Official Website (Vite + Three.js)

Modern cinematic company website with **3D animated background** powered by Three.js + GSAP.

## Features

- Real-time 3D neon grid + particles + floating shapes (Three.js)
- Camera moves with scroll & mouse (parallax)
- GSAP scroll-triggered animations throughout
- High-quality car / night city imagery
- Fully responsive (mobile / tablet / desktop)
- PS5 gaming focus
- Preloader, smooth scroll, contact form

## Quick Start

```bash
npm install
npm run dev
```

Opens → **http://localhost:3000**

## Commands

| Command           | Description                     |
|-------------------|---------------------------------|
| `npm run dev`     | Dev server + hot reload         |
| `npm run build`   | Production build → `dist/`      |
| `npm run preview` | Preview production build        |

## Notes

- Three.js automatically reduces particle/shape count on mobile
- Falls back to CSS gradient if reduced-motion is preferred
- Update social links & emails in `index.html`
- Deploy the `dist/` folder after `npm run build`
